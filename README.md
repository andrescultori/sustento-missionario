# Sustento (nome provisório)

Protótipo clicável de um app para missionários cuidarem dos seus mantenedores: ofertas, agradecimentos, lembretes de cuidado, importação de planilha e relatório mensal.

**⚠️ Nome provisório.** Todos os dados são fictícios; nada é salvo, enviado ou coletado pelo protótipo (o estado fica só na memória do navegador).

👉 **Experimente:** https://andrescultori.github.io/sustento-missionario/

## Como é feito

Um único arquivo estático, `docs/index.html` (HTML + CSS + JS puro, PT/EN, tema claro/escuro). Sem build, sem dependências, sem backend. O GitHub Pages serve a pasta `docs/` da branch `main`.

Para ver localmente: abra `docs/index.html` no navegador.
